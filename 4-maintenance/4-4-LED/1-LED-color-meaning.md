# 4.4.1 LED 색상별 로봇 상태

협동로봇 베이스 및 플랜지에 장착된 LED는 로봇의 상태를 나타냅니다. LED 색상 및 깜빡임에 따른 로봇 상태는 아래 표와 같습니다.

| LED 색상 | 깜빡임 | 상태 |
| :--- | :---: | :--- |
| 빨간색 | X | - 에러 <br> - 비상 정지 |
| 노란색 | O | - 경고 <br> - 자동 운전 & 사람 탐지에 따른 감속 |
| 녹색 | X | - 자동 운전 & 사람 미탐지 <br> - 자동 운전 & radar 미사용 |
| 파란색 | O | - 직접 교시 모드 |
| 파란색 | X | - 수동 운전 & 모터 ON |
| 흰색 | X | - 수동 운전 & 모터 OFF |
