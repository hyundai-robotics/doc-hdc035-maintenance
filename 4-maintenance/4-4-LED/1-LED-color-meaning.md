# 4.4.1 LED colors

The LEDs mounted on the collaborative application’s base and flange indicate the robot’s status. The table below shows the robot's status based on LED color and blinking.

| LED color | Blinking | Status |
| :--- | :---: | :--- |
| Red | X | - Error <br> - Emergency stop |
| Yellow | O | - Warning <br> - Automatic operation & Deceleration according to person detection  |
| Green | X | - Automatic operation & No person detection <br> - Automatic operation & Radar not used |
| Blue | O | - Direct teaching mode |
| Blue | X | - Manual operation & Motor ON |
| White | X | - Manual operation & Motor OFF |
