# 4.3.2.1 연결 및 표시

컨트롤 보드 개요

컨트롤 보드는 2차 엔코더, 센서 유닛, 제어기와의 통신을 담당하는 핵심 모듈이다. 외부 장치와의 안정적인 데이터 송수신을 위해 다양한 접속 장치를 제공한다.

접속 장치 구성

2차 엔코더 포트 : 2차 엔코더 신호 입력 및 피드백 전송

센서 유닛 인터페이스 : 레이더 센서 데이터 수집 및 모니터링

제어기 통신 포트 : 상위 제어기와의 실시간 EtherCAT 통신 지원
